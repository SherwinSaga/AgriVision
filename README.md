# AgriVision
AgriVision is an Android application designed for multi-class classification of rice diseases as part of a research study titled:
**"AgriVision: An Ensemble-Based Classification of the 5 Major Rice Diseases in Region 7, Philippines."**

This application leverages machine learning to assist farmers and agricultural professionals in identifying and managing rice diseases more effectively.


## Features
- Multi-class classification of the 5 major rice diseases in Region 7, Philippines.
     - Brown Spot, Narrow Brown Spot, Bacterial Leaf Blight, Rice Blast, Sheath Blight, Healthy
- User-friendly interface
- Powered by a Tensorflow Lite (TFlite) model for mobile optimized performance

[Agrivision Ensemble Model (model.tflite)](https://drive.google.com/drive/folders/1C3OHxKLUSiitVCuSzhsOA2wTpQuaZryk?usp=sharing)


## How it Works
1. Open the app on your android device.
2. Use the camera or upload an image of the rice leaf.
3. The application will process the image using the integrated TFLite model and classify the disease.
4. View the results with confidence score
